developers talk to users and own features from database to UI.

- **Location:** Helsinki area, hybrid. Fully remote within Finland is also fine.
- **Team:** a small team (up to about ten developers) that reviews code and writes tests.
- **Growth:** room to learn more AWS and AI tooling on real work, not only on side projects.
